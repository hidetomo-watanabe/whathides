VISION

WhatHidesは、スタートアップエコシステムを拡張し、スタートアップの市場価値を最適化します。

  • スタートアップへの面での支援

    • 現場を巻き込んだ事業戦略策定
    • 採用と業務委託を交えた組織体制構築
    • スタートアップと大手企業の協業促進
    • 長期的資本政策策定

SERVICE

WhatHidesは、スタートアップの成長ステージに応じて支援の形を変えます。投資家との連携を通じて、事業と資本の両面から市場価値の最適化を進めます。

  • シード / アーリー

    起業家・スタートアップへの紹介と壁打ち。初期の事業仮説を検証し、必要な人材・企業をつなぎます。

  • ミドル / レイター 〜 IPO前後

    VCと連携しながら、投資先スタートアップへ面での支援を提供します。現場を巻き込んだ事業戦略策定、採用と業務委託を交えた組織体制構築、大手企業との協業促進、長期的資本政策の策定を一体で進めます。

  • 拡大期 / 安定期

    PEファンドによる投資局面で、スタートアップとファンドの双方に投資支援を行います。
